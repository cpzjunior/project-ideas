# Contributing

Thank you for your interest in contributing to Project Ideas!

This repository is a collaborative collection of project ideas and proposals. Any contribution that adds value to the initiative is welcome.

## How to Contribute

1. Fork the repository.
2. Create a branch for your contribution.
3. Make your changes.
4. Submit a Pull Request to the `main` branch.
5. Wait for the review.

For larger changes, we recommend opening an Issue before getting started.

## Guidelines

- Keep content clear, concise, and well-organized.
- Follow the existing structure and Markdown formatting.
- Avoid duplicate or overly generic content.
- Prioritize original ideas and practical applications.
- Include references whenever using third-party content.
- Maintain consistency across languages and repository structure.

The project's primary language is Brazilian Portuguese (`pt-BR`). Translations should preserve the meaning of the original content.

## Pull Requests

Every Pull Request should include:

- A clear and descriptive title.
- A description of its purpose and changes.
- References used, when applicable.

Before submitting, check formatting, spelling, and compliance with the project's guidelines.

## Licensing

By contributing, you agree that your content will be distributed under the [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/) license.

Make sure you have the necessary rights to submit the material.

## Code of Conduct

Maintain a respectful, collaborative, and constructive attitude. Everyone is welcome, regardless of experience or technical background.

Thank you for contributing to Project Ideas!
