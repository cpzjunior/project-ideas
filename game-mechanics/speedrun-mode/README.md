# Speedrun Mode

## Description

A game mode designed to provide native support for speedrunning, allowing players to use specific settings, mechanics, and gameplay behaviors to complete the game in the shortest possible time.

The mode provides features traditionally used by the speedrunning community, such as skipping cutscenes, quickly restarting sections of the game, displaying a timer, and tracking split times. It also allows players to configure which glitches and gameplay quirks can be used, including the preservation of behaviors from previous game versions.

An important characteristic is its independence from the installed game version. Players can use the latest version of the game and select behaviors and rulesets compatible with historical speedrunning categories, without having to install older or modified versions.

The mode also allows specific glitches or all glitches to be disabled, making glitchless speedruns possible. This way, different competition categories can coexist within the same game version, each with its own rules and configurations.

## Functionality

  * A dedicated game mode for speedrunning, with specific settings to optimize attempts.
  * Ability to skip cutscenes and other non-interactive sequences.
  * Quick restart of levels, checkpoints, or entire attempts.
  * Individual configuration of permitted glitches, including the option to disable all of them for glitchless categories.
  * Preservation of glitches and gameplay quirks from previous versions, allowing historical techniques to be reproduced even after game updates.
  * Compatibility with different speedrunning rulesets and categories, such as Any%, Glitchless, and 100%.
  * Independence from the installed game version, allowing players to use the latest version of the game without losing compatibility with mechanics and routes from previous versions.
  * Built-in timer to track attempt times, with support for Real Time Attack (RTA) and In-Game Time (IGT).
  * Automatic split timing using events such as level completion, boss defeats, and checkpoint activation.
  * Comparison of current performance against personal records, indicating whether the player is ahead of or behind their best times.
  * Attempt history and personal best time storage.
  * Ability to view a previous run through a ghost run system, allowing players to compare their current performance with a reference attempt.
  * Identification of the settings and rules used in each attempt, ensuring transparency and compatibility with leaderboards and competitions.

## Applications

  * Platform and action games with speedrunning communities.
  * Adventure and exploration games with different progression routes.
  * Games with glitches, advanced movement techniques, and sequence-breaking possibilities.
  * Games that receive frequent updates and aim to preserve compatibility with historical routes and records.
  * Games with competitive communities that use different speedrunning categories and rulesets.
  * Games that aim to provide official support for speedrunners without relying on external modifications, older versions, or third-party tools.

## References

  * Speedrunning: a competitive gaming discipline in which the objective is to complete a game or achieve a specific goal in the shortest possible time.
  * LiveSplit: an external tool used by the speedrunning community for timing, split tracking, and performance comparison.
  * Glitchless Speedrunning: a speedrunning category in which the use of glitches is prohibited.
  * Any%: a speedrunning category in which the objective is to complete the game as quickly as possible, generally without requiring the completion of optional content.
