# Contextual HUD

## Description

A contextual interface system in which the HUD remains hidden during most of the experience and appears temporarily only when the player holds down a specific button.

When the command is activated, essential information such as health, ammunition, map, objectives, and other relevant indicators are displayed on the screen. When the button is released, the interface automatically disappears, restoring an unobstructed view of the environment.

The goal is to reduce visual clutter, increase immersion, and allow players to check information when necessary without keeping permanent elements occupying screen space.

## Functioning

- HUD hidden by default during exploration and gameplay.
- Dedicated button to temporarily display the interface.
- Display of essential information, such as health, ammunition, map, and objectives.
- Automatic hiding when the button is released.
- Ability to configure which information appears in the contextual HUD.
- Entrance and exit animations to make visual transitions unobtrusive.
- Compatibility with different devices and control schemes.

## Applications

- Action-adventure games.
- FPS and tactical shooter games.
- RPGs and exploration games.
- Survival games.
- Simulators that prioritize immersion and environmental awareness.
