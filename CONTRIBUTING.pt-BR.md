# Contribuindo

Obrigado pelo interesse em contribuir com o Project Ideas!

Este repositório é uma coletânea colaborativa de ideias e propostas de projetos. Toda contribuição que agregue valor à iniciativa é bem-vinda.

## Como contribuir

1. Faça um Fork do repositório.
2. Crie uma branch para sua contribuição.
3. Realize as alterações.
4. Envie um Pull Request para a branch `main`.
5. Aguarde a revisão.

Para mudanças maiores, recomendamos abrir uma Issue antes de iniciar o trabalho.

## Diretrizes

- Mantenha o conteúdo claro, objetivo e organizado.
- Siga a estrutura e a formatação Markdown existentes.
- Evite conteúdos duplicados ou excessivamente genéricos.
- Priorize ideias originais e aplicações práticas.
- Inclua referências sempre que utilizar conteúdos de terceiros.
- Preserve a consistência dos idiomas e da organização do repositório.

O idioma original do projeto é o português brasileiro (`pt-BR`). Traduções devem preservar o significado do conteúdo original.

## Pull Requests

Todo Pull Request deve apresentar:

- Título claro e descritivo.
- Descrição do objetivo e das alterações realizadas.
- Referências utilizadas, quando aplicável.

Antes de enviar, verifique a formatação, a ortografia e a adequação do conteúdo às diretrizes do projeto.

## Licenciamento

Ao contribuir, você concorda que seu conteúdo será disponibilizado sob a licença [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Certifique-se de possuir os direitos necessários sobre o material enviado.

## Código de conduta

Mantenha uma postura respeitosa, colaborativa e construtiva. Todas as pessoas são bem-vindas, independentemente de experiência ou conhecimento técnico.

Obrigado por contribuir com o Project Ideas!
