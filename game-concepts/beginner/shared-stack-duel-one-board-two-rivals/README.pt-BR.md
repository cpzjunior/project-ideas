# Shared Stack Duel: One Board, Two Rivals

## Conceito

Jogo de puzzle competitivo inspirado nos clássicos jogos de blocos, no qual dois jogadores compartilham o mesmo tabuleiro e se alternam para posicionar peças que caem continuamente.

A cada rodada, a velocidade de queda das peças aumenta progressivamente, elevando a pressão e reduzindo o tempo disponível para tomar decisões. Além de organizar as peças para completar linhas e manter o tabuleiro sob controle, cada jogador precisa considerar como seu posicionamento afetará as possibilidades do adversário.

A mecânica de tabuleiro compartilhado transforma uma experiência tradicionalmente individual em uma disputa direta, na qual cada movimento pode beneficiar quem joga ou criar dificuldades para o próximo participante. O espaço limitado e a velocidade crescente tornam a partida progressivamente mais caótica e competitiva.

## Objetivo

Resistir por mais tempo que o adversário, evitando que uma peça ultrapasse o topo do tabuleiro durante a sua vez.

## Mecânicas principais

- Tabuleiro único compartilhado por dois jogadores.
- Alternância de turnos para posicionamento das peças.
- Peças que caem continuamente durante cada turno.
- Velocidade de queda progressivamente maior a cada rodada.
- Organização de peças para completar e eliminar linhas.
- Interferência indireta no adversário por meio do posicionamento das peças.
- Condição de derrota quando uma peça ultrapassa o limite superior do tabuleiro.
- Vitória determinada pela sobrevivência do último jogador.

## Referências

- Tetris.
- Jogos competitivos de puzzle baseados em blocos.
